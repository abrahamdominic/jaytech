## Image Guidelines

- **Format**: Use `.jpg` for photographs and `.png` for logos/graphics with transparency
- **Quality**: Compress images to under 500KB where possible for fast page loading
- **Aspect Ratios**: Maintain consistent aspect ratios within each category
- **Content**: Use real, high-quality images of solar panels, Starlink equipment, electrical work, and Nigerian settings
- **Optimization**: Run images through an optimizer (e.g., TinyPNG, Sharp) before committing
- **Alt Text**: Ensure all `<img>` tags in the codebase include descriptive alt text referencing the image content

## Adding New Images

1. Place the image file in `public/images/`
2. Update the relevant database record or settings to reference the new path
3. Reference images in code using `/images/filename.ext`
4. Update this README if adding new images to the inventory
